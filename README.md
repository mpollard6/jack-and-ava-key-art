# Jack and Ava, 16x9 key art

Proposed cover artwork for the feature film *Jack and Ava* (2024), presented against the
artwork currently running on Prime Video.

This repository exists only to host a single static page. Open the published page rather
than the source: https://mpollard6.github.io/jack-and-ava-key-art/

Artwork is prepared from the film's own graded frames and the release poster logotype.
Nothing in the covers is generated or composited.
